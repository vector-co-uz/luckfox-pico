# Pico Config 2 — Alpine / Luckfox Mini B

Самостоятельное терминальное меню в духе dietpi-config. Запуск от root:

```sh
pico-config
```

Интерфейс на английском для совместимости с UART. Стрелки — навигация,
Enter — выбор, Tab — переход между кнопками, Esc — отмена.

## Установка на работающую плату

Распакуйте архив на плате и из его каталога выполните:

```sh
sh install-pico-config.sh
pico-config
```

Установщик предназначен только для Alpine. Нужны Интернет, репозитории
main/community вашей версии Alpine, записываемая корневая система и свободное
место. NFS/SMB добавляют зависимости; NFS может подтянуть Python.
Установщик не меняет адреса, пароль или автозапуск служб.

## Интеграция в репозиторий прошивки

Архив содержит новые/изменённые файлы, это не полный SDK. Объедините его
содержимое с корнем vector-co-uz/luckfox-pico, сохранив существующие файлы
overlay. Не заменяйте каталог overlay целиком. Существующий workflow
сборки main.yml остаётся в репозитории.

bootstrap.sh устанавливает зависимости и сохраняет /var, включая каталоги
служб и базы пакетов. rootfs.sh добавляет меню, модули и MOTD, выставляет
права и прекращает сборку при ошибках. Рабочий образ сборки увеличен до
256 MiB; размер разделов NAND этим НЕ изменяется. Вместимость конечного
образа во flash нужно проверить при сборке.

## Разделы меню

| Раздел | Возможности |
|---|---|
| Packages | Список, поиск, сведения, установка, удаление, обновление индексов и пакетов; предварительный показ плана |
| Backup | Архив выбранных сетевых, временных, SSH- и APK-настроек; просмотр и восстановление одного файла |
| Mounts | ext2/3/4, FAT, exFAT; NFSv4, SMB3; отключение и сохранение записи в fstab |
| Logs | Последние сообщения ядра и syslog, журнал OpenRC при наличии, процессы |
| Services | Все службы /etc/init.d: состояние, запуск, остановка, перезапуск, включение/отключение в default/boot/sysinit |
| Users / SSH | Создание/удаление обычных пользователей, пароль, блокировка пароля, публичные ключи, парольный вход SSH |
| GPIO | Контроллеры/линии, чтение свободной линии, удержание LOW/HIGH до закрытия диалога |
| Internet | IPv4/DHCP eth0 и usb0, DNS, адреса, маршруты, ping, DNS-проверка, просмотр APK-репозиториев |
| Time | Часовой пояс, ручная дата, NTP-сервер, состояние chrony, применение текущей поправки |
| Devices | USB, блочные устройства, MTD/UBI, сетевые интерфейсы, GPIO, модули, I2C/SPI/UART/video, файловые системы |
| MOTD | Включение/отключение сводки при входе; отдельно доступна команда pico-status |

MOTD показывает hostname, Alpine/ядро, время, uptime, среднюю нагрузку CPU
за 1/5/15 минут (не проценты), доступную RAM и swap, датчики температуры с
их именами, IPv4/IPv6, шлюзы, диски и свободное место. Если ядро не
предоставляет датчик, отображается соответствующее сообщение.
Сводка работает только в интерактивной оболочке, без запросов в сеть;
не добавляет вывод к scp/sftp и удалённым командам.

## Особенности и ограничения

- Сеть и hostname применяются после перезагрузки; DNS и часовой пояс сразу.
  DHCP может перезаписать DNS. Сложный interfaces с include, bridge, VLAN
  или hooks нужно менять вручную. Маски: /8 и /16–/30. Для локальной USB-связи
  шлюз можно оставить пустым. Wi-Fi, NAT/раздача Интернета и VPN не настраиваются.
- Backup — не образ диска: без пользовательских данных, базы паролей,
  SSH-ключей и SMB-паролей. Симлинки пропускаются. Восстановление допускает
  только фиксированный список обычных файлов до 1 MiB каждый. Службы не
  перезапускаются. Восстановление /etc/apk/world не устанавливает пакеты.
- Mounts не форматирует разделы. Точки монтирования: /mnt/pico-ИМЯ.
  По умолчанию предлагается read-only. Записи имеют noauto: после перезагрузки
  используйте Mount saved entry. SMB-пароль сохраняется отдельно в
  /etc/pico-config/credentials с режимом 600; в fstab находится путь к нему.
  Удаление сохранённой записи — вручную через fstab.
- NFS/SMB и локальные ФС требуют поддержки ядра. Пакет не добавляет драйвер
  в Rockchip-ядро. NFSv3, SMB1, сетевые ресурсы с пробелами в пути и
  автоматическое монтирование при загрузке не включены.
- GPIO использует libgpiod v1/v2 и /dev/gpiochip*. Номер — смещение в
  контроллере, а не контакт разъёма. Меню не меняет pinmux и не освобождает
  линии драйверов. После закрытия диалога или перезагрузки уровень не
  гарантируется. Нельзя управлять выводами питания, NAND или занятого UART.
- В SSH меняется PasswordAuthentication, а не PermitRootLogin. Проверяются
  синтаксис и эффективное значение, при конфликте файл откатывается.
  До отключения пароля проверьте отдельный вход по ключу. Условия Match
  могут задавать отдельные правила для клиентов.
- Блокировка пароля не блокирует SSH-ключи. Удаление пользователя сохраняет
  домашние файлы. Удаление и блокировка root через меню запрещены.
- Журналы доступны только если их собирает служба. Syslog включается через
  Services. Постоянная запись журналов во flash автоматически не включается.
- Обновление APK не обновляет ядро, загрузчик или прошивку Rockchip.
  Автоотката сети по таймеру нет.

## Проверка

```sh
sh tests/pico-config.sh
sh tests/modules.sh
```

Добавлен workflow pico-config-check.yml для Ubuntu и Alpine ash.
Тестируются валидация, сохранение другого интерфейса, файловые резервные
копии, пути восстановления, отмена APK-операций (команды подменяются),
расчёт MOTD по тестовым данным и тишина неинтерактивного входа.

В Windows прошли синтаксические, сетевые, модульные тесты и тесты MOTD.
Полный тест файловых прав и резервных копий требует Linux; Linux CI ещё
не запускался. Прошивка, реальные NFS/SMB и GPIO на Mini B не проверены.
